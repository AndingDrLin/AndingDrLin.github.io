# 第4章：静电场边值问题

## 1. 概述

第3章给出了泊松方程 $\nabla^2\varphi = -\rho/\varepsilon$ 和拉普拉斯方程 $\nabla^2\varphi = 0$，但没有告诉你如何求解。本章提供三种方法：

| 方法 | 适用场景 | 考试重要性 |
|------|----------|------------|
| 泊松方程积分解 | 无界空间，已知电荷分布 | 了解 |
| 镜像法 | 电荷 + 规则导体边界 | **重中之重** |
| 分离变量法 | 规则区域的一般边值问题 | 了解 |

本章考试重点集中在镜像法，尤其是以下构型：导体平面、导体球、垂直导体平面、导体半球。Q3 全部四小问都考镜像法。

---

## 2. 泊松方程的积分解（简）

无界空间中，已知电荷分布 $\rho(\vec{r}\,')$，任意场点 $\vec{r}$ 的电势由叠加原理直接积分：

$$\varphi(\vec{r}) = \frac{1}{4\pi\varepsilon} \int_{V'} \frac{\rho(\vec{r}\,')}{|\vec{r} - \vec{r}\,'|} \, dV'$$

其中 $G(\vec{r}, \vec{r}\,') = \dfrac{1}{4\pi\varepsilon|\vec{r} - \vec{r}\,'|}$ 称为格林函数，物理含义是**单位点电荷的电势**。上式本质上是把连续电荷分布视为无数点电荷的叠加。

**局限**：此公式仅适用于**无界空间**。有导体边界时，需要额外满足边界条件——这就引出了镜像法和分离变量法。

---

## 3. 唯一性定理

**结论**：在区域 $V$ 内，满足泊松方程（或拉普拉斯方程）**且**满足边界上全部给定条件的解是**唯一的**。

- Dirichlet 条件（边界上 $\varphi$ 给定）：解唯一
- Neumann 条件（边界上 $\partial\varphi/\partial n$ 给定）：解唯一到常数
- 混合条件：解唯一

**为什么是镜像法的理论基础**：镜像法本质是"猜测"一个解（用假想电荷构造），然后验证它满足方程和边界条件。唯一性定理保证：只要验证通过，这个猜测的解就是**唯一正确答案**。没有它，即使验证了也不能排除存在其他解的可能。

---

## 4. 镜像法

### 4.1 核心思想

1. **去掉导体**，在导体内部适当位置放置**假想电荷**（镜像电荷）
2. 调整镜像电荷的**位置和大小**，使原来导体表面位置成为**等势面**（通常 $\varphi = 0$）
3. 有效区域内（导体外部），真实电荷 + 镜像电荷的叠加场 = 真实物理场
4. **导体内部**镜像法不成立（实际导体内部 $\varphi = \text{常数}$，$\vec{E} = 0$）

**关键**：镜像电荷的位置和大小由边界条件严格确定，不是随意放的。

### 4.2 点电荷 + 无限大接地导体平面

**设置**：导体平面 $z = 0$（接地，$\varphi = 0$），点电荷 $q$ 在 $(0, 0, h)$，$h > 0$。

**镜像电荷**：

$$q' = -q, \quad (0, 0, -h)$$

**有效区域**：$z > 0$

**电势**（$z > 0$）：

$$\varphi(x,y,z) = \frac{q}{4\pi\varepsilon_0}\left(\frac{1}{R_1} - \frac{1}{R_2}\right), \quad R_1 = \sqrt{x^2+y^2+(z-h)^2},\; R_2 = \sqrt{x^2+y^2+(z+h)^2}$$

在 $z = 0$ 上 $R_1 = R_2$，故 $\varphi = 0$。验证通过。

**感应电荷面密度**（Q3(a) 重点）：

$$\boxed{\rho_s(x,y) = -\frac{qh}{2\pi(x^2 + y^2 + h^2)^{3/2}}}$$

推导：由 $\rho_s = \varepsilon_0 E_n$，$E_n = -\partial\varphi/\partial z|_{z=0}$。负号表示感应电荷为负（正电荷吸引负电荷到表面）。距离电荷投影点越近（$\rho = \sqrt{x^2+y^2}$ 越小），$|\rho_s|$ 越大。

**总感应电荷**：对全平面积分得 $Q_{\text{induced}} = -q$（等于镜像电荷大小）。

**作用力**（$q$ 受到的力 = $q$ 与镜像 $-q$ 的库仑力，距离 $2h$）：

$$\boxed{F = -\frac{q^2}{16\pi\varepsilon_0 h^2}\,\hat{z}}$$

负号 = 吸引力。

**短例**：$q = 2\,\text{nC}$，$h = 0.5\,\text{m}$，代入得 $F \approx -36\,\text{nN}$（吸引力）。

**扩展**：如果导体平面**不接地**且中性（总电荷为零），上半空间的电场分布与接地情况相同，但平面电势不再是零，而是浮到某个待定常数。

---

### 4.3 点电荷 + 接地导体球

**设置**：导体球半径 $a$，球心在原点，接地（$\varphi = 0$）。点电荷 $q$ 在 $z$ 轴上距球心 $d$ 处（$d > a$）。

**镜像电荷**：

$$\boxed{q' = -\frac{a}{d}q, \quad b = \frac{a^2}{d}}$$

$q'$ 在 $z$ 轴上距球心 $b$ 处（$b < a$，镜像在球内）。

**推导思路**：球面上任一点 $P$（$r = a$，极角 $\theta$），由余弦定理：
$$R_1^2 = a^2 + d^2 - 2ad\cos\theta, \quad R_2^2 = a^2 + b^2 - 2ab\cos\theta$$

要求 $\varphi|_P = \frac{1}{4\pi\varepsilon_0}\big(\frac{q}{R_1} + \frac{q'}{R_2}\big) = 0$，即 $\frac{R_1}{R_2} = -\frac{q}{q'} = \text{常数}$。将 $b = a^2/d$ 代入得 $R_2 = \frac{a}{d}R_1$，从而 $R_1/R_2 = d/a$（与 $\theta$ 无关），进而 $q' = -aq/d$。

**重要区分**：
- $b = a^2/d$ → **位置关系**（球面反演，$b \cdot d = a^2$）
- $q' = -aq/d$ → **电荷关系**（有 $a/d$ 因子）
- 两个公式不同！不要混淆。

**球面感应电荷面密度**：

$$\rho_s(\theta) = -\frac{q(d^2 - a^2)}{4\pi a(d^2 + a^2 - 2ad\cos\theta)^{3/2}}$$

$\theta = 0$ 对应最靠近 $q$ 的方向。总感应电荷 $= q' = -aq/d$。

**作用力**（$q$ 与 $q'$ 的库仑力，距离 $d - b = \frac{d^2-a^2}{d}$）：

$$\boxed{F = -\frac{q^2 a d}{4\pi\varepsilon_0(d^2 - a^2)^2}}$$

- $d \to a$ 时（电荷贴近球面），$F \to \infty$
- $d \gg a$ 时，$F \approx -\dfrac{q^2 a}{4\pi\varepsilon_0 d^3}$（比平面的 $1/d^2$ 衰减更快）

**短例**：$a = 0.1\,\text{m}$，$d = 0.3\,\text{m}$，$q = 10\,\text{nC}$。则 $q' = -3.33\,\text{nC}$，$b = 3.33\,\text{cm}$，$F \approx -4.2\,\mu\text{N}$。

---

### 4.4 点电荷 + 不接地/带电导体球

**设置**：导体球带总电荷 $Q$（不接地）。其他同 4.3。

**方法**：接地解 + 球心补偿电荷。

1. 接地情况：镜像 $q' = -aq/d$ 在 $b = a^2/d$ 处，球面总感应电荷 $= q'$
2. 在**球心**放置补偿电荷 $Q_c = Q - q' = Q + aq/d$，使总电荷达 $Q$
3. 球心到球面各点等距（均为 $a$），故球面仍为等势面

**球外电势**：

$$\varphi = \frac{1}{4\pi\varepsilon_0}\left(\frac{q}{R_1} + \frac{q'}{R_2} + \frac{Q + aq/d}{r}\right)$$

**球面电势**：

$$\boxed{\varphi_{\text{sphere}} = \frac{Q + aq/d}{4\pi\varepsilon_0 a}}$$

**特殊情况**：$Q = 0$（中性不接地球），球面电势 $\neq 0$，球心补偿 $+aq/d$。

---

### 4.5 线电荷 + 接地导体圆柱

**设置**：无限长接地导体圆柱（半径 $a$，轴线沿 $z$），线电荷 $\rho_l$ 平行于轴线，距轴心 $d$（$d > a$）。

**镜像线电荷**：

$$\boxed{\rho_l' = -\rho_l, \quad b = \frac{a^2}{d}}$$

**关键**：镜像线电荷**等大反号**，**没有** $a/d$ 的缩放因子！与球的情况不同：
- 三维（球）：电势 $\propto 1/R$，需 $q' = -aq/d$ 使球面电势为零
- 二维（圆柱）：电势 $\propto \ln R$，只需 $\rho_l' = -\rho_l$ 就可使柱面为等势面

**电势**（柱坐标 $\rho, \phi$）：

$$\varphi(\rho, \phi) = \frac{\rho_l}{2\pi\varepsilon_0}\ln\frac{R_2}{R_1} + C$$

其中 $R_1, R_2$ 为场点到 $\rho_l$ 和 $\rho_l'$ 的距离，$C$ 为满足 $\varphi|_{\rho=a}=0$ 的常数。

**单位长度力**：

$$F/L = -\frac{\rho_l^2 d}{2\pi\varepsilon_0(d^2 - a^2)}$$

---

### 4.6 两个垂直的半无限大接地导体平面 【Q3(b) 必考】

**设置**：两个接地半无限大导体平面分别位于 $x = 0$（$y \ge 0$）和 $y = 0$（$x \ge 0$），互相垂直。点电荷 $q$ 在第一象限 $(a, b)$（$a, b > 0$）。

**镜像系统**（共需 3 个镜像电荷）：

| 电荷 | 位置 | 说明 |
|------|------|------|
| $-q$ | $(-a, b)$ | 关于 $x = 0$ 平面的镜像 |
| $-q$ | $(a, -b)$ | 关于 $y = 0$ 平面的镜像 |
| $+q$ | $(-a, -b)$ | 两个镜像的镜像（第二次镜像，双负得正） |

**为什么需要 3 个**：$-q$ 在 $(-a, b)$ 使 $x = 0$ 平面等势，但它破坏了 $y = 0$ 平面的等势条件（因为它也在 $y > 0$ 区域），需要对它再做关于 $y = 0$ 的镜像。同理，$-q$ 在 $(a, -b)$ 需要对 $x = 0$ 再做镜像。两次"镜像的镜像"恰好重合于 $(-a, -b)$，符号翻两次得 $+q$。

**有效区域**：第一象限（$x > 0, y > 0$）

**一般规律**：若两平面夹角 $\alpha = \pi/n$（$n$ 为整数），则需要 $2n - 1$ 个镜像电荷。本题 $\alpha = \pi/2$，$n = 2$，故需 $3$ 个镜像。

**短例**：$q$ 在 $(1, 2)$，则镜像为 $-q$ 在 $(-1, 2)$、$-q$ 在 $(1, -2)$、$+q$ 在 $(-1, -2)$。第一象限的场 = 这四个点电荷（无导体平面）的叠加。

---

### 4.7 导体半球在接地平面上 【Q3(c) 必考】

**设置**：接地导体平面 $z = 0$，其上有一导体半球（半径 $a$，球心在原点，半球在 $z \ge 0$）。半球与平面**连通**，同为零电势。点电荷 $q$ 在 $z$ 轴上 $z = d$ 处（$d > a$）。

**边界条件**：(1) $z = 0$ 平面上 $\varphi = 0$；(2) 半球面（$r = a, 0 \le \theta \le \pi/2$）上 $\varphi = 0$。

**镜像系统**（共需 3 个镜像电荷）：

| 镜像电荷 | 位置 | 作用 |
|----------|------|------|
| $q_1 = -q$ | $(0, 0, -d)$ | 满足平面 $z = 0$ 上 $\varphi = 0$ |
| $q_2 = -\dfrac{a}{d}q$ | $(0, 0, a^2/d)$ | $q$ 关于球面的镜像 |
| $q_3 = +\dfrac{a}{d}q$ | $(0, 0, -a^2/d)$ | $q_1$ 关于球面的镜像 |

**验证思路**：
- 在平面 $z = 0$ 上：$q$ 与 $q_1$ 距平面等距、电荷异号 → 抵消；$q_2$ 与 $q_3$ 同理抵消 → $\varphi = 0$
- 在半球面上：$(q, q_2)$ 是标准球面镜像对 → 球面电势为零；$(q_1, q_3)$ 也是标准球面镜像对 → 球面电势为零。叠加后 $\varphi = 0$

**有效区域**：$z > 0$ 且 $r > a$

**理解方法**：先用平面镜像处理平面边界，再用球面镜像处理半球边界——两个步骤各自独立，互为叠加。

---

### 4.8 镜像法的实际应用 【Q3(d)】

镜像法的核心价值：将复杂的导体边界问题转化为简单的点电荷叠加问题，避免求解偏微分方程。实际应用包括：

- **传输线电容计算**：架空输电线与大地之间构成电容，用地下的镜像线电荷替代大地的影响，可准确计算单位长度电容。这在电力系统设计和信号完整性分析中广泛应用。
- **静电防护与避雷针设计**：分析带电云层对建筑物（近似导体）的电场作用，估算避雷针的保护范围。
- **集成电路互连线**：芯片中导线与衬底（接地平面）之间的寄生电容，用镜像法简化建模。

**本质**：任何涉及"电荷靠近导体表面"的工程问题，只要导体形状可近似为平面、球面或圆柱面，镜像法都是最简洁的求解工具。

## 5. 分离变量法（简）

当边界形状规则但无法用简单镜像替代时，使用分离变量法。

**核心步骤**：设 $\varphi = X(x)Y(y)$ 代入 $\nabla^2\varphi = 0$，得 $X''/X + Y''/Y = 0$。令 $X''/X = -k^2$，则 $Y''/Y = k^2$。

- $X$ 方程：$X'' + k^2 X = 0$ → $X = A\sin(kx) + B\cos(kx)$
- $Y$ 方程：$Y'' - k^2 Y = 0$ → $Y = Ce^{ky} + De^{-ky}$

边界条件决定 $k$ 的取值（本征值 $k = n\pi/a$），通解为所有模式的叠加（傅里叶级数），系数由非齐次边界条件通过正交性积分确定。

**矩形槽标准结果**（$0 \le x \le a$，底边 $\varphi = V_0$，其余接地）：

$$\boxed{\varphi(x,y) = \frac{4V_0}{\pi}\sum_{n=1,3,5,\ldots}\frac{1}{n}\sin\frac{n\pi x}{a}\,e^{-n\pi y/a}}$$

**注意**：$\int_0^a \sin^2\frac{n\pi x}{a}dx = a/2$（傅里叶系数常用），不是 $a$。

**考试提示**：本次考试分离变量法分量较轻，记上述结论和关键步骤即可，不必深究柱坐标（贝塞尔函数）。

## 6. 例题

### 例1：点电荷 + 接地导体平面——求感应电荷密度

**题**：$q = 1\,\text{nC}$ 位于接地导体平面上方 $h = 1\,\text{m}$ 处。求 (1) 导体表面投影点 $(0,0,0)$ 处的感应电荷面密度；(2) 距投影点 $1\,\text{m}$ 处的面密度。

**解**：

(1) 在 $(0,0,0)$，$\rho = \sqrt{x^2+y^2} = 0$：

$$\rho_s(0,0) = -\frac{qh}{2\pi(0 + h^2)^{3/2}} = -\frac{10^{-9} \times 1}{2\pi \times 1} \approx -1.59 \times 10^{-10}\,\text{C/m}^2$$

(2) 在 $\rho = 1\,\text{m}$，$R = \sqrt{1^2 + 1^2} = \sqrt{2}$：

$$\rho_s = -\frac{10^{-9} \times 1}{2\pi(2)^{3/2}} = -\frac{10^{-9}}{2\pi \times 2\sqrt{2}} \approx -5.63 \times 10^{-11}\,\text{C/m}^2$$

面密度随距离增大而迅速减小。

---

### 例2：点电荷 + 接地导体球——求力的极限情况

**题**：接地球半径 $a$，点电荷 $q$ 距球心 $d$。验证：(1) $d \gg a$ 时力趋近于平面的结果；(2) $d \to a$ 时力发散。

**解**：

力公式 $F = -\dfrac{q^2 a d}{4\pi\varepsilon_0(d^2 - a^2)^2}$。

(1) $d \gg a$：$d^2 - a^2 \approx d^2$，$F \approx -\dfrac{q^2 a}{4\pi\varepsilon_0 d^3}$。令 $a \to \infty$（球面退化为平面）且 $h = d - a$，可以恢复到平面公式 $F = -q^2/(16\pi\varepsilon_0 h^2)$（略去推导细节）。关键是：远距离时球的作用比平面弱——$1/d^3$ vs $1/d^2$。

(2) $d \to a$：分母 $(d^2 - a^2)^2 \to 0$，$F \to -\infty$。物理上：电荷越靠近接地球面，感应电荷越集中且距离越近，吸引力急剧增大。

---

### 例3：导体半球——确定镜像电荷

**题**：接地导体平面 $z = 0$ 上有一导体半球，半径 $a = 0.05\,\text{m}$。点电荷 $q = 5\,\text{nC}$ 在 $z$ 轴上 $d = 0.2\,\text{m}$ 处。求三个镜像电荷的大小和位置。

**解**：

$q_1 = -q = -5\,\text{nC}$，位置 $(0, 0, -0.2)$

$q_2 = -\dfrac{a}{d}q = -\dfrac{0.05}{0.2} \times 5 = -1.25\,\text{nC}$，位置 $z = \dfrac{a^2}{d} = \dfrac{0.0025}{0.2} = 0.0125\,\text{m}$

$q_3 = +\dfrac{a}{d}q = +1.25\,\text{nC}$，位置 $z = -\dfrac{a^2}{d} = -0.0125\,\text{m}$

有效区域 $z > 0, r > 0.05$ 内的电势 = 这四个点电荷（1 个真实 + 3 个镜像）在无界空间中的叠加。

### 答案

**1**：唯一性定理：满足泊松/拉普拉斯方程及全部边界条件的解唯一。镜像法本质上是通过"猜"（构造假想电荷）得到一个候选解，唯一性定理保证只要验证它满足方程和边界条件，就是唯一正确的解。

**2**：$q' = -3\,\text{nC}$，在 $(0, 0, -0.3)$。$\rho_s(0,0) = -\dfrac{3 \times 10^{-9} \times 0.3}{2\pi(0.3^2)^{3/2}} = -\dfrac{9 \times 10^{-10}}{2\pi \times 0.027} \approx -5.3 \times 10^{-9}\,\text{C/m}^2$。$F = -\dfrac{(3 \times 10^{-9})^2}{16\pi\varepsilon_0(0.3)^2} \approx -9.0 \times 10^{-7}\,\text{N}$。

**3**：$q' = -\dfrac{0.15}{0.4} \times 8 = -3\,\text{nC}$，$b = \dfrac{0.15^2}{0.4} = 0.05625\,\text{m}$。

**4**：球心补偿 $Q_c = 3 - (-3) = 6\,\text{nC}$。$\varphi_{\text{sphere}} = \dfrac{6 \times 10^{-9}}{4\pi\varepsilon_0 \times 0.15} \approx 360\,\text{V}$。

**5**：镜像：$-q$ 在 $(-2, 3)$，$-q$ 在 $(2, -3)$，$+q$ 在 $(-2, -3)$。有效区域为第一象限。若点电荷在 $(-1, 2)$（第二象限），则该点**不在有效区域内**，镜像法不能直接以这种形式使用——需要重新分析边界条件。

**6**：三个镜像电荷：(1) $q_1 = -q$ 在 $z = -d$（平面镜像）；(2) $q_2 = -aq/d$ 在 $z = a^2/d$（$q$ 的球面镜像）；(3) $q_3 = aq/d$ 在 $z = -a^2/d$（$q_1$ 的球面镜像）。需要三个是因为平面和球面边界互相影响：平面镜像本身又成为球面的"源"，需要对它再做球面镜像。

**7**：$\rho_l' = -2\,\mu\text{C/m}$，$b = \dfrac{0.03^2}{0.12} = 0.0075\,\text{m} = 7.5\,\text{mm}$。注意：镜像等大反号，无 $a/d$ 因子。

**8**：(1) 架空输电线对地电容：用地下的镜像线电荷替代大地，计算等效电容；(2) 集成电路互连线寄生电容：用镜像法处理衬底接地平面效应。两者都是将导体边界替换为等效镜像电荷，避免直接求解边值问题。

**9**：底边条件 $\varphi(x,0) = 100\sin(\pi x/2)$ 恰好匹配本征函数 $\sin(\pi x/2)$（$n = 1$ 模式）。故只有一项：$\varphi(x,y) = 100\sin(\pi x/2) \cdot e^{-\pi y/2}$。无需傅里叶级数展开。

**10**：$\rho_s = -\dfrac{qh}{2\pi(\rho^2 + h^2)^{3/2}}$。总电荷 $Q = \int_0^\infty \rho_s \cdot 2\pi\rho\,d\rho = -qh\int_0^\infty \dfrac{\rho\,d\rho}{(\rho^2+h^2)^{3/2}}$。令 $u = \rho^2 + h^2$，$du = 2\rho d\rho$，积分得 $Q = -qh \cdot \frac{1}{h} = -q$。总感应电荷等于镜像电荷大小，验证了镜像法的自洽性。
