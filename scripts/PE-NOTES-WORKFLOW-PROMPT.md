你的任务是运行两个自动化工作流脚本，迭代优化电力电子课程笔记，目标是让"看过但没学会"的学生读完修改后的笔记后能在考试中拿到 90 分。

## 背景

- 项目: Astro 静态站点，课程笔记在 src/content/notes/pe-notes/
- 笔记文件: 00-09 共 10 个 .md 文件
- 真题: raw_materials/pe-final/ 下有 2022-2025 四年期末试卷 PDF
- 旧参考试卷: src/content/notes/pe-notes/materials/ 下有 2017/2018 试卷

## 已创建的工作流脚本

1. scripts/pe-notes-phase1.mjs — Gap 分析（7个agent并行分析所有章节与真题的差距，生成修改计划）
2. scripts/pe-notes-phase2.mjs — 迭代改进（持续循环: 扫描→修改→审核→全扫描，连续5轮零问题才停）

## 执行步骤

### Step 1: 运行 Phase 1 Gap 分析

调用 Workflow 工具运行 scripts/pe-notes-phase1.mjs。等待完成后检查 _gap-report.md 输出。

### Step 2: 运行 Phase 2 迭代改进

调用 Workflow 工具运行 scripts/pe-notes-phase2.mjs。这个脚本会:
- 循环处理 24 个修改项（每轮取 3 个最高优先级）
- 每个修改项由 Writer agent 修改笔记，再由 Reviewer agent 做 5 维度审核
- 通过审核的项标记完成，未通过的下轮重试
- 已知 gap 全处理完后进入全扫描模式，8 个 agent 并行扫描所有章节寻找新问题
- 连续 5 轮全面审核零新问题才停止
- 最终运行 8 个验证 agent 逐题打分，输出预估考试得分

### Step 3: 检查结果

运行完成后查看:
- src/content/notes/pe-notes/_final-report.md — 最终评分报告
- 确认预估得分 >= 90%
- 如果低于 90%，查看报告中的 remaining gaps，手动补充或再跑一轮

## 关键约束

1. **运行时间**: Phase 2 必须运行 10 小时以上，除非连续 5 轮零问题提前停止
2. **修改方式**: 原地修改现有章节 .md 文件，不新建文件
3. **审核标准**: 读者"粗略看过笔记但基本没学会"，修改后必须能让他们看懂推导、照着做题、答概念题
4. **内容深度**: 略超纲但帮助理解，不是只列公式
5. **写作规范**: 中文+英文术语双写，LaTeX公式，推导不跳步，保持"先讲清楚/固定套路/别丢分"结构

- SCR相控+推导 (每年5-15分)
- MOSFET损耗链 (每年5-25分)
- 热设计+降额+散热器 (每年2-9分)
- 缓冲电路 (偶考, 8-12分)
- DC-DC变换器推导+计算 (每年20-25分, 最高分值)
- 逆变器/PWM/三相 (每年15-25分)
- 概念文字题 (每年5-10分)
