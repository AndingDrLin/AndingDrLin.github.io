## 课程简介

本系列笔记覆盖动力学与控制课程的主要内容，从动态系统的基本概念出发，逐步讲解控制系统分析、框图化简、稳定性分析，以及 PID 等经典反馈控制策略。

目标读者是需要独立自学、并在期末能独立做题的学生。每章包含核心概念、推导过程、配套例题和易错提醒。
