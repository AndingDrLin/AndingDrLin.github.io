# Part A：考试地图

这份文件不是详细讲义，而是先回答一个问题：**Sample Exam Questions 反复在考什么？**

---

## 1. 样题高频知识块

根据 Sample Set 1–6，重复率最高的主题大致可以分成下面几组：

| 知识块 | 高频题型 | 样题表现 |
|---|---|---|
| DFM | MCQ + 简答 + 讨论 | 反复考 DFM 定义、何时介入、原则、设计比较 |
| Sustainability / 4Rs | MCQ + 简答 | 反复考三大支柱、actionable principles、4Rs |
| Quality / 7QC | MCQ + 长题 | cause-effect diagram、Pareto chart、control chart 高频出现 |
| Robust Design / Taguchi | 长题 + 计算 | quadratic loss、noise factors、quality characteristic |
| Six Sigma / DMAIC / capability | MCQ + 长题 | DMAIC、CTQ、Cp/Cpk 多次出现 |
| PM fundamentals | MCQ + 简答 | project definition、process groups、Talent Triangle |
| Scope / WBS | MCQ + 长题 | WBS 定义、100% rule、分解、画 WBS |
| Schedule / CPM | MCQ + 长题 | critical path、forward pass、backward pass、float |
| Communications | MCQ + 计算 | channels formula、agenda、communication model |
| Risk | MCQ + 简答 | SWOT、risk process、response strategies |
| Conflict management | 长题 | avoiding / accommodating / collaborating / compromising / competing |
| Finance / costing | MCQ + 长题 | NPV、BCR、IRR、cash flow、break-even、make-or-buy |
| Accounting basics | MCQ | EBITDA / EBITA、gross profit、P&L |
| Organization structure | MCQ | divisional / matrix / start-up / formal organisation |

## 2. 按考试感觉分层

### 第一层：几乎必复习

这些题型在多套样题里重复出现：

- DFM definition / principles / early design impact
- sustainability principles / three pillars / 4Rs
- 7QC tools
- control chart
- Six Sigma / DMAIC
- process capability (`Cp`, `Cpk`)
- WBS
- CPM / critical path
- communication channels
- risk identification / response
- break-even / make-or-buy / NPV-BCR-IRR

### 第二层：很可能出变形题

- organizational structure classification
- start-up structure traits
- Talent Triangle / project manager skills
- conflict handling strategies
- P&L / gross profit / EBITDA / EBITA
- cash flow / overtrading

### 第三层：题目里强烈出现，但 slide 支撑未必完整

- detailed accounting interpretation
- enterprise valuation / company present valuation
- defender strategic posture
- EVM (`SPI`, `CPI`)
- leadership vs management
- standard vs regulation
- some business/legal structure items

这些内容建议记住**题型与判断逻辑**，但答题时要保守，不要臆造课程原文。

## 4. 你做题时要先识别的"题目信号词"

| 信号词 | 你应该想到什么 |
|---|---|
| ease of manufacturing, lower cost, fewer parts | DFM |
| current/future generations, environmental/social/economic | sustainability |
| fishbone, Ishikawa, root cause | cause-effect diagram |
| descending bars, few important causes | Pareto chart |
| process over time, stable, UCL/LCL | control chart |
| DMAIC, defect reduction | Six Sigma |
| capability, tolerance, specification, sigma | `Cp` / `Cpk` |
| decomposition, scope, work packages | WBS |
| longest path, float, ES/EF/LS/LF | CPM |
| team members, channels | `n(n-1)/2` |
| threats/opportunities | risk |
| NPV, BCR, IRR | investment appraisal |
| make or buy, fixed cost, variable cost | cost comparison |
| TC = FC + Q×VC | break-even / costing |

## 5. 当前资料的使用边界

本套笔记遵循两个原则：

1. **样题优先**：先看考试怎么问。
2. **slides 佐证**：只把当前已有 slides 能支撑的内容写实。

因此你在使用时要知道：

- DFM / Quality / WBS / Communications / Risk 这几块支撑较强。
- Finance 部分样题很多，但当前 slides 对部分题目的直接支撑较弱，所以我会在 finance 分册里特别标注哪些是 `Partial coverage`。
