## 使用建议

### 考前 3 小时速查

1. 翻 [第6章 公式速查与答题模板](/notes/engineering-project-management-and-finance/06_exam_formulas_and_templates/) — 背公式、看答题步骤
2. 根据薄弱模块回到对应考试专题章节（第7–10章）做练习
3. 遇到概念不清楚的，回 [第1–5章](#基础笔记) 查详细解释

### 考前 1 天系统复习

1. 通读 [第1–5章](#基础笔记)，建立知识框架
2. 精做 [第7–10章](#考试专题) 的练习题，对照答案自查
3. 用 [历年真题参考答案](#历年真题参考答案) 做全真模拟
