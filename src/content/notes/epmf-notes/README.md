## 来源标记说明

- `Slides-backed`：slides 有明确支撑
- `Slides + Sample-backed`：slides 有基础 + 样题确认考法
- `Sample-backed`：样题反复出现，无直接 slides 支撑
- `Exam-only signal`：来源不明，保守记忆
