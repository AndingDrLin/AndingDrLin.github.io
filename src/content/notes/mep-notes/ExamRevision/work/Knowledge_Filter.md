# Knowledge Filter（最终笔记筛选规则）

## 总目标

最终笔记不是 PPT 翻译，而是“考试可直接复述、可画图、可比较”的复习笔记。筛选标准：

1. practice/exam 或考前资料反复出现；
2. 主线 slides 中有明确支撑；
3. 能形成定义、比较、图示、公式或答题模板；
4. 与 microelectronics packaging 的核心矛盾相关：I/O、尺寸、热、可靠性、成本、材料兼容性。

## Keep

| 模块 | 保留内容 | 理由 |
|---|---|---|
| fundamentals | packaging functions、classification、technology waves、Moore's Law for packaging | Chapter 1 和 practice 高频 |
| electrical design | signal/power/ground path、parasitics、frequency challenge、DFR/DFT、environment | Lecture 2 + 考前资料反复出现 |
| materials | underfill/mold/solder/TIM/substrate、thermal/electrical/mechanical/chemical properties | Lecture 3 + practice 高频 |
| CTE / reliability | CTE mismatch、solder fatigue、delamination、moisture、thermal cycling | 最容易写成机制题 |
| assembly technologies | wire bonding、TAB、flip-chip、BGA、CSP、WLP | 比较题高频 |
| microelectronics role | SoC vs SiP、packaging controls performance/cost/reliability | Lecture 4/8 + 学长笔记高频 |
| microsystems/MEMS | MEMS needs environmental interface and hermetic/mechanical packaging | L1/L5 重点提醒 |
| Si processing impact | low-k ILD、die thinning、TSV、interposer、3D integration | L6 + 考前资料 |
| thermal management | conduction、convection、radiation、thermal resistance、cooling hierarchy | exam paper 计算/解释题 |
| answer templates | compare/explain/discuss/draw-with-figure 结构 | 直接服务考试 |

## Compress

| 内容 | 压缩方式 | 原因 |
|---|---|---|
| 课程书单、assessment、教材页码 | Source Inventory 保留，不进正文 | 不服务考试作答 |
