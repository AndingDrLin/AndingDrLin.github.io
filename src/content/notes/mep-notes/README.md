这套笔记按 **考试复习优先** 整理。主线来源是 `封装/slides` 的 Lecture 1-8、Additional Lecture 9 和补充 PDF；practice、past exam、考前资料和学长笔记只用来判断哪些内容高频、该怎样组织答案。

## 考试要会什么

- 先建立整门课的题型地图，再按章节补概念、公式、比较和图示。
- 能用第10章模板组织长答案，用第11章清单检查漏点，用第12章追溯来源。
- 复习时优先处理 P0/P1 高频点，而不是逐页翻译 PPT。

## 一句话记忆

> 这套笔记的用法是“先会答题，再回填知识”，不是把 slides 换一种排版重看一遍。

## 最后 3 小时怎么用

1. 先看 [第0章 考试地图与复习策略](/notes/microelectronics-packaging/00-exam-strategy/) 确认高频题型。
2. 如果题目是 explain / discuss / compare，直接看 [第10章 答题模板](/notes/microelectronics-packaging/10-question-answer-templates/)。
3. 如果题目涉及计算或热管理，看 [第7章 Thermal Management](/notes/microelectronics-packaging/07-thermal-management/)。
4. 考前最后 10 分钟扫 [第11章 Common Mistakes Checklist](/notes/microelectronics-packaging/11-common-mistakes-checklist/)。
