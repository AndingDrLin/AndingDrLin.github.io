这套笔记按期末题反推内容，但不是只列考点。每章先把题目背后的基础讲清楚，再给例题，最后收成固定做题套路。

## 章节

- [第0章 期末题型和学习顺序](/notes/power-electronics/00-exam-strategy/) — 先知道这门课考什么、该按什么顺序补基础。
- [第1章 波形计算](/notes/power-electronics/01-waveform-basics/) — average、RMS、form factor、分段积分和电感电压。
- [第2章 Diodes 与 Rectifiers](/notes/power-electronics/02-diodes-rectifiers/) — 二极管整流、PIV、电容滤波和稳压电源题。
- [第3章 SCR / Thyristor](/notes/power-electronics/03-scr-phase-control/) — SCR 为什么能控、怎么画 firing angle、怎么积分。
- [第4章 Power Switches and Losses](/notes/power-electronics/04-power-switches-losses/) — 功率器件、SOA、diode recovery、MOSFET loss。
- [第5章 Thermal and Heatsink](/notes/power-electronics/05-thermal-heatsink/) — 把损耗变成温升，算 heatsink 和 shared heatsink。
- [第6章 Snubber and Flyback](/notes/power-electronics/06-snubber-flyback/) — 感性负载关断、snubber 保护和 flyback 隔离。
- [第7章 DC-DC Converters](/notes/power-electronics/07-dc-dc-converters/) — Buck、Boost、Buck-Boost、Flyback 和 boundary CCM。
- [第8章 DC-AC Inverters and PWM](/notes/power-electronics/08-dc-ac-inverters-pwm/) — 全桥逆变、PWM、三相线电压和 shoot-through。
- [第9章 真题步骤库](/notes/power-electronics/09-past-paper-worked-examples/) — 把常见题型整理成可套用的板书步骤。

## 使用方法

第一次学，按第 1 章到第 8 章顺序读。每章的例题至少自己盖住答案算一遍。

考前复习，先看第 0 章定位题型，再去对应章节看例题和固定套路，最后用第 9 章检查自己能不能完整写步骤。
